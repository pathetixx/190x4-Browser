# Живая проверка через порт отладки

Сценарии гоняют собранный браузер в отдельном профиле (`BROWSER190X4_PROFILE`)
с портом отладки (`BROWSER190X4_DEBUG_PORT=9333`) на Windows-машине: профиль
пользователя и установленный браузер они не трогают.

1. Сборка и запуск пробы — `E:\test\probe\build-probe.cmd`, `deploy.ps1`,
   `launch.ps1` (или `prep.ps1` — копия установленной версии).
2. Страницы из `pages/` и любой файл `blob.bin` на ~300 КБ — в `E:\test\probe\t\`, `key.ps1` и `input.ps1` — в
   `E:\test\probe\`.
3. Порт на эту машину: `ssh -f -N -p 2222 … -L 19333:127.0.0.1:9333`.
4. `node scripts/probe/tests.mjs [popup,history,ghost,fullscreen,omnibox,split,stop]`,
   `windows.mjs prepare|verify` (между шагами — перезапуск пробы),
   `gui.mjs` — настоящие клавиши и щелчки задачей в сессии пользователя.

Окно, которое закрывает само себя, на вызов уже не ответит: такие вызовы
ждутся с таймаутом. Две пробы на одном профиле делят один процесс движка, и
`/json` показывает окна обеих — перед запуском старую пробу закрыть.
