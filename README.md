# 190x4 Browser

Браузер для Windows 10 и 11 на движке WebView2, в оформлении 190x4.

## Установка

Установщик `190x4-Browser_X.Y.Z_x64-setup.exe` лежит в
[последнем релизе](https://github.com/pathetixx/190x4-Browser/releases/latest).

- Браузер ставится для текущего пользователя, без прав администратора, в
  `%LOCALAPPDATA%\190x4 Browser`.
- Профиль (история, закладки, пароли, сессия, настройки) — в
  `%LOCALAPPDATA%\pw.x190x4.browser`.
- Если в системе нет WebView2, установщик скачает его сам.
- Обновления браузер проверяет сам и ставит по кнопке «Обновить».
- Сделать его браузером по умолчанию — в «Настройки → Браузер по умолчанию».

## Возможности

### Вкладки и окна

- Несколько окон и приватное окно, в котором не сохраняются история, пароли,
  сессия и список загрузок.
- Закреплённые вкладки, группы вкладок и разделённый экран — две вкладки рядом
  в одном окне.
- Вкладку можно перетащить в другое окно или вынести в новое — страница
  переезжает без перезагрузки.
- Окна и вкладки восстанавливаются после перезапуска; вкладки прошлого сеанса
  загружаются, только когда на них переключаются.
- Давно не открытые вкладки засыпают и освобождают память, сохраняя прокрутку и
  введённый текст.
- Командная палитра по Ctrl+K: команды браузера и поиск по открытым вкладкам.

### Адресная строка и страницы

- Подсказки из истории, закладок и поисковой системы, дописывание адреса при
  наборе.
- Масштаб страницы запоминается для сайта.
- Поиск по странице, печать, сохранение страницы, своё меню по правому щелчку.
- Свои страницы ошибок, в том числе для сайта с неверным сертификатом.
- Запросы камеры, микрофона, местоположения и уведомлений показываются у
  адресной строки, выданные разрешения сбрасываются в настройках.
- Браузер может представляться сайтам как Chrome — для всех сайтов или для
  отдельного.

### Закладки и история

- Панель закладок с папками, закладка по Ctrl+D, диспетчер закладок.
- Импорт и экспорт закладок в HTML, перенос закладок и истории из Chrome, Edge,
  Яндекс Браузера, Brave, Vivaldi и Opera.
- Страница истории с поиском, удалением записей и очисткой за час, сутки или
  неделю.

### Пароли

- Браузер предлагает сохранить пароль после входа и подставляет его, в том числе
  во входе в два шага и в формах внутри страницы.
- Под полем входа — список сохранённых учётных записей сайта.
- Пароли зашифрованы средствами Windows; показ и экспорт подтверждаются через
  Windows Hello.
- Импорт и экспорт в CSV.

### Загрузки

- Панель загрузок с паузой, продолжением и отменой, отдельная страница загрузок.

### Защита

- Реклама и трекеры блокируются на всех сайтах, включая встроенные фреймы и
  рекламу в видео YouTube. Списки обновляются каждый день без обновления
  браузера.
- Блокировку можно выключить для отдельного сайта.
- Окна, которые сайт открывает без щелчка, блокируются; разрешить их можно
  значком в адресной строке.
- SmartScreen предупреждает о фишинге и опасных файлах.
- Видео со звуком не запускается само, пока это не разрешено в настройках.

### Видео

- Защищённое видео воспроизводится через Widevine, а если лицензию не дали —
  через PlayReady.
- Видео разворачивается во весь экран кнопкой плеера, F11 разворачивает окно.

### Новая вкладка

Часы, поиск, плитки сайтов, погода и монитор ресурсов: сколько памяти,
процессора и видеокарты занимают браузер и каждая вкладка.

### Расширения

Встроены в браузер, включаются и закрепляются на панели через кнопку
«Расширения».

| Расширение | Что делает |
|---|---|
| Переводчик | Переводит вставленный или выделенный на странице текст (Ctrl+Shift+U). Работает через сервер 190x4. |
| Загрузчик видео | Скачивает видео и звук с YouTube, VK, Rutube и других сайтов (Ctrl+Shift+D). Работает через сервер 190x4. |
| SponsorBlock | Пропускает в видео YouTube спонсорские вставки, просьбы подписаться и другие сегменты, отмеченные зрителями. |
| Автопролистывание | Сменяет доигравший ролик в YouTube Shorts, Reels в Instagram и TikTok следующим. |
| Twitch | Трансляции в полном качестве, автоматический сбор бонусов баллов канала, смайлы BetterTTV и FrankerFaceZ в чате. |

| Клавиши | Действие |
|---|---|
| Ctrl+T, Ctrl+W | новая вкладка, закрыть вкладку |

| Ctrl+N, Ctrl+Shift+N | новое окно, новое приватное окно |
| Ctrl+Tab, Ctrl+1…9 | переключение вкладок |
| Ctrl+L, Alt+D, F6 | адресная строка |
| Ctrl+K | командная палитра и поиск вкладок |
| Ctrl+F, F3, Shift+F3 | поиск по странице |
| Ctrl+D | добавить в закладки |
| Ctrl+Shift+B, Ctrl+Shift+O | панель закладок, диспетчер закладок |
| Ctrl+H, Ctrl+J | история, загрузки |
| Ctrl+Shift+Del | удалить данные о работе в браузере |

## Сервисы 190x4

Переводчик и загрузчик видео включаются файлом
`%LOCALAPPDATA%\pw.x190x4.browser\services.json`:

```json
{ "base_url": "https://190x4.pw", "translate_key": "…", "media_key": "…" }
```

Без него браузер работает полностью, а эти два расширения показывают, что
сервис не настроен.

## Чего пока нет

- Перевода страницы целиком.
- Синхронизации между устройствами.
- Автозаполнения адресов и банковских карт.
- Расширений из магазина Chrome.

## Разработка

### Устройство

Интерфейс браузера — веб-страница поверх окна, вкладки — отдельные вебвью
WebView2 в том же окне, логика — на Rust (Tauri 2). Все окна делят один
процесс приложения и одно окружение WebView2.

```
crates/adblock    фильтр рекламы и трекеров
crates/webview    вкладки на WebView2 (только Windows)
crates/store      история, закладки, сессия, загрузки, настройки, пароли (SQLite)
crates/services   клиент сервисов 190x4: переводчик и загрузчик видео
crates/spike      замеры памяти, задержки фильтра и защищённого видео
src-tauri         приложение: команды, состояние, установщик
ui                интерфейс браузера и всплывающие окна, без сборщиков
pages             встроенные страницы: новая вкладка
scripts           релиз, списки фильтров, иконки, проверки на Windows
docs              устройство браузера и замеры
```

### Интерфейс без сборки

Интерфейс открывается в любом браузере на заглушках:

```bash
python3 -m http.server 8777 --directory ui
```

Адрес — `http://127.0.0.1:8777/index.html`. Параметры:

- `?demo=palette|find|settings|downloads|history-page|shield|bookmarks|history` — готовое состояние;
- `&section=passwords` — раздел настроек;
- `?motion=off` — без анимаций;
- `popup.html?kind=menu|downloads|bookmark|bookmark-folder|group|media|translate|password|accounts|site` — всплывающее окно.

### Сборка

Нужны Windows, Rust stable (`rust-toolchain.toml`) и Node.js 22.

```powershell
pwsh scripts/fetch-lists.ps1
npx @tauri-apps/cli@2.11.4 build -c '{"bundle":{"createUpdaterArtifacts":false}}'
```

Установщик появится в `target/release/bundle/nsis`. Первая команда скачивает
списки фильтров — в репозитории их нет. Без параметра `-c` сборке нужен ключ
подписи обновлений.

### Отдельный профиль

- `BROWSER190X4_PROFILE=<папка>` — запуск с отдельным профилем, независимо от
  установленного браузера.
- `BROWSER190X4_DEBUG_PORT=<порт>` — вместе с отдельным профилем открывает порт
  отладки движка.
